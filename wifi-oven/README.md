# Канал Wi-Fi: счётчик печи Дала СА4-Э720

Трёхфазный счётчик печи опрашивает ESP32 через преобразователь MAX485 и сам публикует показания по Wi-Fi прямо в брокер платформы, в топик `opentwins/lower_lab:oven`. Цикл опроса — около 40 секунд: пауза 30 с плюс сам опрос.

| Параметр | Значение |
|---|---|
| Протокол | IEC 62056-21, 4800 бод, 7E1 |
| Особенность | Преамбула `7F 7F 7F` перед каждым кадром, чтение командой R2 |
| Выводы ESP32 | RX 16, TX 17, DE/RE 4 |
| Двойник | `lower_lab:oven` |

Эскиз для счётчика Saiman (без преамбулы, команда R1) этому счётчику не подходит — именно из-за этого в начале сентября двойник печи перестал обновляться.

## Прошивка

1. Скопируй `firmware/esp32_mqtt_li_reader/secrets.example.h` в `secrets.h` рядом с ним и впиши имя и пароль Wi-Fi. Файл `secrets.h` в Git не попадает.
2. Arduino IDE 2, плата **ESP32 Dev Module**, библиотеки **PubSubClient** и **ArduinoJson**.
3. Загрузи `esp32_mqtt_li_reader.ino` и проверь журнал на 115200.

## Известная проблема

Прошивка перезагружает ESP32 после 20 неудачных попыток подключиться к брокеру, но ждёт подключения к Wi-Fi без ограничения по времени. 30 сентября 2026 г. после короткого перерыва на стороне сети канал так и не восстановился сам. Стоит добавить тайм-аут ожидания Wi-Fi и сторожевой таймер.

Подробное описание узла — в [отчёте по трёхфазному счётчику](../docs/reports/Отчет%20Трехфазный%20счетчик.pdf).
